# Object-Oriented Implementation of Tic-Tac-Toe with AI Integration

This repository contains a research paper titled **"Object-Oriented Implementation of Tic-Tac-Toe with AI Integration"**, authored by Namrata Mali, Ayush Kumar Gupta, **Sai Mani Ritish Upadhyayula**, and Vidhiben Ashokbhai Vanani. The paper demonstrates the development of a modular and interactive Tic-Tac-Toe game in Python using OOP principles along with the Minimax AI algorithm.

## 📚 Abstract
This project showcases how OOP principles—encapsulation, inheritance, abstraction, and polymorphism—can be used to structure a classic Tic-Tac-Toe game. An unbeatable AI player is implemented using the Minimax algorithm with heuristic evaluation for 5x5 grid support, making it a challenging and engaging gameplay experience.

## 🧠 Key Features
- Object-Oriented Design (Classes: Player, Renderer, Logger, AIPlayer, etc.)
- AI opponent using the **Minimax algorithm**
- Supports 3x3 and 5x5 grids
- Efficient heuristic approach to avoid recursion depth issues
- Modular, maintainable, and extensible architecture
- Move logging and restart feature
